My entry for **One Letter for Your Day** — a single character that sums up the
day. Run it and it writes exactly one uppercase letter to `/output/entry.txt`.

## The letter

The letter is **K**.

The hidden word: **K** stands for **kernel-panic** — the one word that captures
a day that just stops and dumps its guts on the floor.

## Run

```bash
python3 main.py
cat /output/entry.txt   # -> K
```

Stdlib only, no dependencies.
